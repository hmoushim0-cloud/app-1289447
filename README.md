## بنية المنصة والشاشات التشغيلية (Application Architecture)

### 1. مستكشف المنشآت وقاعدة البيانات الحية (`explorer` / `home`)
- **لوحة المؤشرات العليا (KPI Cards):**
  - إجمالي المنشآت الموثقة بجدة: **1,420 منشأة**
  - الكافيهات والمقاهي المختصة: **640 مقهى**
  - المطاعم والمطابخ السحابية: **510 منشأة**
  - المخابز ومعامل الحلويات: **270 مخبز**
- **الفلاتر التفاعلية متعددة الأبعاد:**
  - فلترة أحياء جدة: (حي الروضة، حي الزهراء، شارع التحلية، حي الشاطئ، حي الحمراء، حي السلامة، حي أبحر، حي البلد).
  - تصنيف المنشأة: (كافيهات، مطاعم، مخابز، مطابخ سحابية، تموين وفنادق).
  - أصناف الأغذية والمجمدات المطلوبة: (مجمدات لحوم ودواجن، مخبوزات وعجائن مجمدة، ألبان وأجبان، بطاطس ومقبلات مجمدة، فواكه وهريس مجمد).
  - شريط بحث ذكي باسم المنشأة، الحي، أو الصنف.
- **بطاقات المنشآت الموثقة:**
  - تفاصيل المنشأة (الاسم العربي والإنجليزي، الحي، الشارع الدقيق، السجل التجاري).
  - نوع وسعة التخزين التبريدي الفعلي (غرف تبريد Walk-in، مجمّدات رأسية، سعة بالمتر المكعب m³).
  - مسؤول المشتريات المباشر مع رقم جوال محجوب جزئياً (`05541•••••`) مع إمكانية المعاينة السريعة.
  - زر تصدير مباشر لملف Excel / CSV متوافق بالكامل مع ترميز اللغة العربية (UTF-8 with BOM).

### 2. نموذج بيانات المنشأة وباني الحملات المخصص (`details`)
- **نموذج ملف العميل الميداني (Dossier Preview):**
  - استعراض الحقول الـ 18 الاستقصائية التي يجمعها الباحث الميداني لكل منشأة:
    1. الاسم والسجل التجاري والفرع الدقيق.
    2. الموقع الجغرافي والإحداثيات على خرائط Google.
    3. اسم ورقم التواصل المباشر مع مدير المشتريات والتوريد.
    4. أصناف المجمدات المطلوبة وفجوة المورد الحالي وأسباب الاستبدال.
    5. معدل الاستهلاك الأسبوعي وسعة الفريزر وأوقات استلام الشحنات وشروط الدفع الائتمانية.
- **باني الحملات البحثية المخصصة (Campaign Builder):**
  - حزم B2B مدروسة ومطابقة لواقع السوق:
    - **حزمة المسح الميداني المركّز (100 منشأة)**: 750.00 ر.س (3 أيام عمل).
    - **حزمة التغطية الميدانية الشاملة (250 منشأة)**: 1,500.00 ر.س (5 أيام عمل - الأكثر طلباً).
    - **حزمة الهيمنة السوقية والذكاء التجاري VIP (500 منشأة)**: 2,500.00 ر.س (10 أيام عمل).
  - تخصيص القطاعات والأحياء وأصناف المنتجات المطلوبة مع حقول إدخال اسم الشركة والملاحظات الميدانية.

### 3. متابعة تقدم جمع وتدقيق البيانات والفوترة (ZATCA Phase 2) (`checkout` / `tracking`)
- **شريط متابعة تدقيق البيانات الواقعي (Data Collection Pipeline):**
  - المرحلة 1: تحديد النطاق الجغرافي والحصر الأولي (مكتمل 100%).
  - المرحلة 2: التحقق الميداني والهاتفي من مسؤولي المشتريات (جاري العمل - تم توثيق 78 من 100 منشأة).
  - المرحلة 3: تدقيق الجودة وتصدير ملف Excel / CSV وربط CRM.
- **تنزيل المخرجات:**
  - تنزيل فوري للملف المعتمد بصيغة CSV المتوافقة مع Microsoft Excel.
- **الفاتورة الضريبية الإلكترونية (ZATCA Compliant):**
  - احتساب الضريبة بدقة متناهية (`totalCalculationExact`: السعر الأساسي + 15% ضريبة القيمة المضافة بالهللات).
  - نافذة فحص الحمولة التشفيرية لرمز الاستجابة السريع (QR TLV Base64).
  - بوابات سداد مخصصة للمنشآت: مدى (Mada)، Apple Pay، وتحويل بنكي رسمي إلى مصرف الإنماء مع زر نسخ الآيبان.
